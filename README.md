# Occupancy Estimation - Biblioteca Fernão Mendes Pinto
Estimativa de ocupação da Biblioteca Fernão Mendes Pinto (BGUM, Campus de Gualtar) através da monitorização passiva de probe requests WiFi.
Baseado em técnicas de passive WiFi sensing, o sistema captura e processa probe requests para inferir o nível de ocupação.
## Estrutura
- `wifi-occupancy/` — captura, processamento e dashboard (Streamlit)
- `SA2026_paper_8264.pdf` — paper submetido à SA2026
- `uji_probes.pdf` — documento de referência (UJI probes dataset)
- `demo.png` — mapeamento da sala
